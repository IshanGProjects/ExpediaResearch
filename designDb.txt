Method | Route                                   | Description
GET    | /users/:userId/itineraries              | Fetch all itineraries for a user
GET    | /users/:userId/itineraries/:itineraryId | Fetch specific itinerary
POST   | /users/:userId/itineraries              | Create a new itinerary
PUT    | /users/:userId/itineraries/:itineraryId | Update an existing itinerary
DELETE | /users/:userId/itineraries/:itineraryId | Delete an itinerary
